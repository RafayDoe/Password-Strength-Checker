# Password-Strength-Checker
A simple React app that checks the strength of passwords.

## Features
1. Live password strength detection
2. Clean and responsive UI.
3. Checks for: 
- Length
- Numbers
- Capital Letters
- Special Characters
4. Color coded strength label.
5. Animated strength bar.

## How it works
1. Weak: Fails most conditions.
2. Medium: Meets some conditions.
3. Strong: Meets all conditions.

## How to install
- Clone this repository.
```sh
git clone https://github.com/RafayDoe/Password-Strength-Checker.git
```
- Navigate to current folder.
- Install Dependencies.
- Start the development server.
